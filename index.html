plug-in os manufacturing framework

Echo OS is a plug-and-play operating system: write the ISO to a USB stick, boot any x86_64 machine into a full desktop, and install offline in minutes — nothing on your disk is touched until you say so. Every layer is a swappable component: bring your own bootloader and assemble your own OS. It is built to carry Aira, the AI-on-OS layer*, as a first-class system layer: in development, and never shipped quietly.

    echo.boot()

    Own the first signal. Boot entries, initramfs, and live boot assets live in one component — BIOS and UEFI paths stay explicit instead of hiding inside a monolithic profile.

    Read the boot component
    .boot-entries/ vm capture

    echo.core()

    The body of the system: the Arch base, the KDE Plasma 6 live session with SDDM autologin, and the live/target boundary. All of it branded: wallpaper, panel, SDDM theme, installer.

    Explore echo-core
    .live-login/ lightdm · earlier preview

    echo.install()

    The handoff. Calamares copies the live system straight to the target disk — entirely offline. No mirrors, no network setup, no hidden download step.
